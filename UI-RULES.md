# UI-Regeln — bindend

1. Genau ein Element pro Bildschirm nutzt die Akzentfarbe als Füllung.
2. Kein Datum und keine Aufgabe erscheint zweimal auf einem Bildschirm.
3. Sechs Rollen: display/section/title/body/meta/label. Keine anderen
    Größen, keine anderen Gewichte.
4. Letter-spacing NUR auf Großbuchstaben-Labels. Niemals auf Text mit
    Bindestrich.
5. Fünf Abstände: 8/16/24/40/64.
6. Eine Erhebungsebene. Keine Karte in einer Karte. Listen sind ein
    Container mit Trennlinien, nicht n Karten.
7. Datumsangaben: tabular-nums in der Body-Schrift. Mono nirgends.
8. Nichts wird hinzugefügt, ohne dass etwas entfernt wird.

## Vor dem Code

Abschnittsreihenfolge und pro Element die Rolle ausgeben.
Auf Freigabe warten. Dann implementieren.
