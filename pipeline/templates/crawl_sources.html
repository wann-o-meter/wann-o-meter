Crawl Sources

Each source is a scoped crawl config in pipeline/config/crawl_sources/<id>.yaml (id, seed_url, category, scope.allowed_domains, scope.path_prefix, max_depth, formats, event_type_hint, schedule) - add a new source by creating a file there, no code required. Running a source crawls it within its configured scope, extracts events, and either writes already-reviewed ones straight to data/ or queues new ones for Review.
