Crawl Sources

Each source is a scoped crawl config in pipeline/config/crawl_sources/<id>.yaml (id, seed_url, category, scope.allowed_domains, scope.path_prefix, max_depth, formats, event_type_hint, schedule) - add one with the form below, or hand-write the file directly, no code required either way. Running a source crawls it within its configured scope, extracts events, and either writes already-reviewed ones straight to data/ or queues new ones for Review.
